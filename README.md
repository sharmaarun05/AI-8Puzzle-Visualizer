# AI 8-Puzzle Problem Solver Visualizer

**Course:** Artificial Intelligence  
**Registration Number:** 24BCE2946  
**Assigned Algorithm:** Breadth First Search (BFS) (Algorithm 1)  

## Project Description
This repository contains an interactive web application developed from scratch to solve the 8-Puzzle Problem using the **Breadth First Search (BFS)** algorithm. It visually demonstrates state-space exploration, real-time node generation, and pathfinding to the goal state.

## Technologies Used
- HTML5
- CSS3 (Vanilla UI without heavy frameworks)
- JavaScript (ES6)

## Implemented Features
1. **Initial and Goal State Control:** Allows custom input or randomly generated puzzles.
2. **Interactive Visualization:** Animates and renders the board as BFS searches.
3. **Real-Time Data Metrics:** Tracks generated nodes, expanded nodes, search depth, execution time, and memory usage.
4. **Algorithm Selection & Comparison:** BFS implemented with a static comparison table against DFS, DLS, IDDLS, GBFS, and A* for analytical benchmarking.
5. **Detailed Algorithm Info:** Shows time/space complexities and working principles.

## How to Run
Simply open `index.html` in your preferred web browser. Click the **Run BFS** button to begin the visualizer.
