4. Algorithm Information (BFS)

Description & Working Principle: Breadth-First Search (BFS) is an uninformed search algorithm that explores the state space tree level by level. It expands the shallowest unexpanded node first using a FIFO Queue for the Frontier.

Advantages: Guarantees the shortest path (optimal) if step cost is uniform.

Limitations: High memory requirement because it stores all nodes in memory.

Time Complexity: O(b^d) | Space Complexity: O(b^d) | Completeness: Yes | Optimality: Yes
